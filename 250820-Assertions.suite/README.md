# Notes

[![](https://img.shields.io/badge/YouTube-14m26s-FF0000?logo=youtube)](https://youtu.be/yQikfuc-mjA)

Join Eggplant Research and Developer, Doug Simons, to learn more about Eggplant's English-like language **SenseTalk** and its capabilities.

### Topics
- Using `assert` with boolean expressions to validate conditions
- Providing an optional message to an assertion for clarity
- Default assertion behavior: throws an exception on failure
- Controlling failure behavior with `the AssertionBehavior` global property (`Exception`, `Error`, `Warning`, `Pause`)
- Enabling and disabling all assertions with `the AssertionsEnabled` global property
- Using assertions inside handlers to validate parameters
- Custom pass/fail handling with `assertionPassedDelegate` and `assertionFailedDelegate`
- Reporting results with assertion count properties: `assertionPassCount`, `assertionFailCount`, `assertionErrorCount`, `assertionWarningCount`, `assertionExceptionCount`
