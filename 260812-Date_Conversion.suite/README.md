# Notes

[![](https://img.shields.io/badge/YouTube-18m18s-FF0000?logo=youtube)](https://youtu.be/08fWOkYw8wk)

Join Eggplant Research and Developer, Doug Simons, to learn more about Eggplant's English-like language **SenseTalk** and its capabilities.

### Topics
- The `clockFormat` global property — switching between 12-hour and 24-hour display
- The `centuryCutoff` property — controlling how 2-digit years are interpreted
- Localizing date display with `dateLocale` (e.g. Spanish month and weekday names)
- Date format "varieties" (`dateFormatVariety`, `dateInputVariety`) — resolving `mm/dd` vs. `dd/mm` ambiguity
- Understanding date/time **value vs. format**: a value's position on the timeline is independent of how it is displayed
- Using the `convert` command to change a date/time value's display format
- Reading and setting the `.format` property directly on a date variable
- Time zones: accessing and changing `timeZoneOffset`, `timeZone`, and `timeZoneAbbreviation` on a date value
- UTC and Zulu time: `the UTC time`, `the Zulu time`, and `convert … to zulu time`
- Date comparisons: `is a date`, `comes before`, and using `date()` for unambiguous comparisons
