# SenseTalk Eggspert Sessions

Short, focused [SenseTalk](https://en.wikipedia.org/wiki/SenseTalk) video sessions hosted by Doug Simons of Keysight Eggplant. Each session explores a specific language feature with live code examples.

> All sessions are hosted by **Doug Simons** — founder and main maintainer of [SenseTalk](https://en.wikipedia.org/wiki/SenseTalk), and Eggplant Research and Developer at Keysight.

## <img src="https://forums.eggplantsoftware.com/favicon.ico" width="20"/> About Eggplant Functional

[Eggplant Functional](https://www.keysight.com/us/en/products/design-engineering-software/software-quality-engineering/automation-intelligence-eggplant-test.html) is Keysight's image-based test automation tool. Unlike traditional automation frameworks that rely on object IDs or DOM access, Eggplant interacts with any application — on any platform or device — exactly as a real user would: by looking at the screen.

- **SenseTalk** is its built-in scripting language — English-like, human-readable, and purpose-built for test automation
- **Any UI, any platform** — web, desktop, mobile, embedded, or mainframe; no app instrumentation required
- **Fusion Engine** combines image recognition, OCR, and AI to find and interact with on-screen elements
- Scripts live in **`.suite`** folders and run directly inside **Eggplant Studio** (VS Code extension) or the classic Eggplant Functional IDE

The sessions in this repo explore SenseTalk as a language — all scripts run standalone and do not require a connected device.
