# Notes

[![](https://img.shields.io/badge/YouTube-18m18s-FF0000?logo=youtube)](https://youtu.be/08fWOkYw8wk)

Join Eggplant Research and Developer, Doug Simons, to learn more about Eggplant's English-like language **SenseTalk** and its capabilities.

### Topics
- Recognizing date inputs in many formats with `is a date`
- Built-in output formats: `short date`, `abbreviated date`, `long date`, `common date`, `international date`, `internet date`, `simple date`, and their `long` variants
- The `timeFormat` global property — reading and customizing individual format tokens
- The `clockFormat` global property — switching between 12-hour and 24-hour display
- The `timeInputFormat` global property — controlling how date strings are parsed
- Adding custom input formats to `timeInputFormat` using bracket-style tokens
- The `formattedTime()` function for fully custom date/time output
- Preserving a date's timeline value independently of its display format using the `.format` property
- Using `as date with format` to store a date with a specific display format
