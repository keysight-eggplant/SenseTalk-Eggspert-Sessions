# Notes

[![](https://img.shields.io/badge/YouTube-17m44s-FF0000?logo=youtube)](https://youtu.be/3pZLOCGqiEQ)

Join Eggplant Research and Developer, Doug Simons, to learn more about Eggplant's English-like language **SenseTalk** and its capabilities.

### Topics
- Defining SenseTalk objects with `properties … end properties` declarations
- Using `my` and `me` to access an object's own properties from within its script
- Customizing object display with `asTextFormat`
- Creating new object instances with `new BankAccount with {…}`
- Sending messages to objects using `send … to`, `tell … to`, and dot notation
- Building object hierarchies: a customer object owning named account objects
- Computed properties implemented as handlers (e.g. `wealth` totalling all account balances)
- Using `repeat with each` over the `values of` a property list of objects
- Structured reporting with a `displayReport` handler
