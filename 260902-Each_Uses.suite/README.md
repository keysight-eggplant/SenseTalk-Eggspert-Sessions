# Notes

[![](https://img.shields.io/badge/YouTube-13m51s-FF0000?logo=youtube)](https://youtu.be/CVd7gb22Cwc)

Join Eggplant Research and Developer, Doug Simons, to learn more about Eggplant's English-like language **SenseTalk** and its capabilities.

### Topics
- Extracting list values with `each character/word/line/item of`
- Using custom item delimiters: `each item delimited by ";" of`
- Transforming values into a new list (squaring, appending suffixes, calling a function `for each`)
- Filtering with `where`, `which`, and `whose` clauses
- Generating lists from expressions: random values, combining words from two sources
- Using `each` as a **container** to selectively update values in place
- Applying bulk constraints: `set each item … to each but never less than … but no more than …`
- Combining two `each` expressions for cross-product results
