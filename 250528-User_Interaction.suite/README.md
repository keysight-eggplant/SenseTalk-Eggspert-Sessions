# Notes

[![](https://img.shields.io/badge/YouTube-13m29s-FF0000?logo=youtube)](https://youtu.be/C9eusVfThTU)

Join Eggplant Research and Developer, Doug Simons, to learn more about Eggplant's English-like language **SenseTalk** and its capabilities.

### Topics
- Displaying output and separators with `put`
- Audio feedback using `beep` and `play`
- Displaying dialogs with `answer` and `answer ... with` for user choices
- Collecting free-text input with `ask`
- List-based selection with `answer ... from list` (single and multiple selections)
- Advanced `answer` options: error dialogs, timeouts, and custom icons
- File and folder picker dialogs with `answer file`, `answer folder`, and `ask file`
- Using `resourcePath()` to reference suite resource files
